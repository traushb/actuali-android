First public testing release of Actuali for Android, an unofficial Android port of Matt Farrell's Actuali iOS app for Actual Budget.

- Kotlin + Jetpack Compose with Material 3 Expressive, warm orange styling, and light/dark mode.
- Envelope and tracking budgets, accounts, add/edit/split transactions, reports, schedules, rules, bank sync, and offline-first CRDT sync.
- Android 8.0+ (`minSdk 26`); application ID `io.github.traushb.actuali`.
- Server addresses are hidden from the More overview card.

**The attached APK is signed with an Android debug key and is intended for testing.** A production signing key is needed for production distribution. Its separate package installs alongside builds that use `com.mfazz.actuali`; it does not migrate their existing local data.

Ported with Claude Code (Claude Opus 5.5), directed and tested by traushb. MIT licensed; original Matt Farrell and James Long / Actual Budget notices are preserved.
